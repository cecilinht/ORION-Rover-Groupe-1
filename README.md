
# ORION-Rover
## Groupe 1 - ORION UNIVERSITY

### 1. Présentation
ORION-Rover est un robot livreur autonome intelligent destiné au transport de colis sur le campus universitaire.

### 2. Objectifs
- Suivre une piste au sol.
- Détecter et éviter les obstacles.
- Reconnaître les panneaux de signalisation.
- Effectuer des livraisons autonomes.
- Afficher la position du robot sur une interface Web.

### 3. Technologies
- ESP32
- Arduino IDE
- Python
- Flask
- OpenCV
- TensorFlow / Keras
- HTML, CSS, JavaScript
- Git et GitHub

### 4. Organisation
- Electronique
- Robotique
- Intelligence artificielle
- Développement Web
- Mathématiques

### 5. Équipe
Groupe 1 - 5 étudiants

### 6. Durée
10 jours ouvrés.

### 7. Établissement
ORION UNIVERSITY - Madagascar
